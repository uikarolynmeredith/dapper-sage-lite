# dapper-sage-lite

gRPC · Next.js · PostgreSQL

给自己省点事的小工具

## 用法

```bash
cat data.txt | go run main.go
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/dapper-sage-lite.git
cd dapper-sage-lite
go build ./...
```
